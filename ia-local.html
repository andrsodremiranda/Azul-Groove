Usando IA local (Ollama, LM Studio, Jan)

Este guia explica como o site conversa com uma IA no seu computador e como evitar o erro "Não consegui conectar" ou "blocked by CORS".

Como funciona

As mensagens não passam pelo nosso servidor. Quem fala com a IA é o seu próprio navegador, direto no programa que está no seu PC.

Site (HTTPS)→Seu navegador→127.0.0.1 (seu PC)→Ollama / LM Studio / Jan

Como o site e o programa local são "origens" diferentes, o navegador só entrega a resposta se o programa disser, por um cabeçalho chamado CORS, que aquele site pode ler. Sem isso, o servidor até responde (status 200), mas o navegador bloqueia.

Importante: isso só funciona no mesmo computador onde a IA roda. No celular ou em outro aparelho, 127.0.0.1 é o próprio aparelho, então use um provedor na nuvem (OpenAI, OpenRouter, Groq...).

Checklist rápido

  1. O programa está aberto e o servidor local está iniciado?
  2. Tem um modelo baixado e carregado?
  3. O CORS (ou hosts confiáveis) está liberado para azul-groove.vercel.app?
  4. Você aceitou a permissão de rede local que o navegador pede?
  5. A URL no ⚙️ está certa e termina em /v1?

Passo a passo por programa

Ollama (mais simples)
  1. Feche o Ollama completamente (inclusive o ícone da bandeja).
  2. Inicie liberando a origem:

Windows (PowerShell):

$env:OLLAMA_ORIGINS="*"; ollama serve

Linux / Mac:

OLLAMA_ORIGINS="*" ollama serve
  1. Baixe um modelo: ollama pull llama3.2
  2. No ⚙️ do site: provedor Ollama (no seu PC). URL: http://127.0.0.1:11434/v1. Chave vazia.

Para restringir só ao seu site, troque * por https://azul-groove.vercel.app.

LM Studio
  1. Baixe e carregue um modelo.
  2. Abra a aba Developer e ligue o servidor (Start).
  3. Nas configurações do servidor, ative Enable CORS (reinicie o servidor depois).
  4. No ⚙️ do site: provedor LM Studio (no seu PC). URL: http://127.0.0.1:1234/v1.
Jan
  1. Abra Settings > Local API Server.
  2. Se existir CORS ou Trusted Hosts (hosts confiáveis), ative/adicione azul-groove.vercel.app (ou *).
  3. Defina uma API Key (qualquer texto) e use a mesma no site.
  4. Pare e inicie o servidor de novo depois de mudar.
  5. No ⚙️ do site: Outro (compatível com OpenAI). URL: http://127.0.0.1:1337/v1. Clique em "Buscar modelos disponíveis" e escolha o modelo.
Algumas versões do Jan não têm mais a opção de CORS. Nesse caso, atualize o Jan, use Ollama/LM Studio ou use o proxy abaixo.
Proxy de CORS (quando o programa não permite liberar)

Um mini script em Python que recebe a chamada do site, acrescenta o cabeçalho de CORS e repassa ao programa. Salve como cors_proxy.py e rode python cors_proxy.py. Depois use http://127.0.0.1:1338/v1 no ⚙️ (em vez da porta original).

from http.server import ThreadingHTTPServer, BaseHTTPRequestHandler
import urllib.request, urllib.error

TARGET = "http://127.0.0.1:1337"   # porta do seu programa (Jan)
PORT = 1338                         # porta do proxy

class H(BaseHTTPRequestHandler):
    def cors(self):
        self.send_header("Access-Control-Allow-Origin", "*")
        self.send_header("Access-Control-Allow-Headers", "Authorization, Content-Type")
        self.send_header("Access-Control-Allow-Methods", "GET, POST, OPTIONS")
        self.send_header("Access-Control-Allow-Private-Network", "true")
    def do_OPTIONS(self):
        self.send_response(204); self.cors(); self.end_headers()
    def fwd(self):
        n = int(self.headers.get("Content-Length") or 0)
        body = self.rfile.read(n) if n else None
        h = {k: v for k, v in self.headers.items()
             if k.lower() in ("authorization", "content-type")}
        req = urllib.request.Request(TARGET + self.path, data=body,
                                     headers=h, method=self.command)
        try:
            r = urllib.request.urlopen(req, timeout=600)
        except urllib.error.HTTPError as e:
            r = e
        data = r.read()
        self.send_response(r.getcode())
        self.send_header("Content-Type", r.headers.get("Content-Type", "application/json"))
        self.send_header("Content-Length", str(len(data)))
        self.cors(); self.end_headers(); self.wfile.write(data)
    do_GET = do_POST = fwd

ThreadingHTTPServer(("127.0.0.1", PORT), H).serve_forever()

Permissão de rede local

Navegadores novos (Chrome, Edge) perguntam se o site pode acessar dispositivos na sua rede local. Permita. Se você negou sem querer, clique no ícone ao lado do endereço do site > Configurações do site > libere "Rede local" e recarregue (Ctrl+F5).

Safari costuma bloquear sites HTTPS acessando http://127.0.0.1. Nele, prefira Chrome, Edge ou Firefox, ou um provedor na nuvem.

Como testar a conexão

Abra o site, aperte F12 > Console e rode:

fetch('http://127.0.0.1:1337/v1/models').then(r=>r.json()).then(console.log)

Troque a porta pela do seu programa (Ollama 11434, LM Studio 1234, Jan 1337).

O que apareceO que significa
Lista de modelosTudo certo.
blocked by CORS / falta Access-Control-Allow-OriginO servidor responde, mas o CORS/hosts confiáveis não está liberado.
ERR_CONNECTION_REFUSEDServidor desligado ou porta errada.

Não quer mexer em nada disso? Escolha um provedor na nuvem no ⚙️ (OpenAI, OpenRouter, Groq, Gemini). Eles não precisam de CORS: basta colar a chave.
