POLÍTICA DE PRIVACIDADE – ASTM Software

1. Coleta de Dados

Durante o uso do bot e de nossos serviços, podem ser coletadas as seguintes informações:

Dados de Uso:

  • Músicas tocadas;
  • Comandos utilizados;
  • Interações realizadas com o bot.

Dados Técnicos:

  • Logs de erro;
  • IDs de servidores e canais;
  • Nome do servidor;
  • Informações técnicas relacionadas ao funcionamento do sistema.

Rich Presence:

Informações de erro relacionadas ao Rich Presence podem ser registradas localmente para fins de diagnóstico. Esses dados não são enviados automaticamente à ASTM Software.

2. Finalidade da Coleta

Os dados são utilizados exclusivamente para:

  • Melhorar o desempenho do serviço;
  • Corrigir falhas técnicas;
  • Desenvolver novos recursos;
  • Prevenir atividades maliciosas;
  • Oferecer uma melhor experiência ao usuário.

3. Armazenamento e Segurança

A ASTM Software adota rigorosas medidas técnicas para proteger os dados coletados, incluindo:

  • Criptografia durante a transmissão e armazenamento;
  • Controle restrito de acesso;
  • Monitoramento e proteção contra invasões;
  • Revisões periódicas de segurança.

4. Compartilhamento de Dados

A ASTM Software não vende, aluga ou compartilha dados com terceiros, exceto:

  • Quando exigido por lei ou ordem judicial;
  • Mediante consentimento explícito do usuário.

5. Direitos do Usuário

O usuário pode solicitar a qualquer momento:

  • Acesso aos dados armazenados;
  • Correção de informações incorretas;
  • Exclusão permanente de dados (respeitando limitações legais e técnicas).

Solicitações devem ser feitas diretamente pelo e-mail:
📧 corporationastm@gmail.com

6. Atualizações da Política

Esta Política pode ser atualizada periodicamente para refletir melhorias no sistema. Mudanças relevantes serão publicadas nos canais oficiais da ASTM Software.
